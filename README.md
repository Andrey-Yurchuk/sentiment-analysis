# Классификатор тональности русских твитов: TF-IDF + MLP

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Andrey-Yurchuk/sentiment-analysis/blob/main/notebooks/sentiment_tfidf_mlp.ipynb)

Бинарный классификатор тональности (позитив / негатив)
на корпусе русскоязычных твитов RuTweetCorp. Классический подход TF-IDF + многослойный перцептрон (MLP),
анализ весов модели и разбор того, где у такого подхода заканчивается «понимание» текста.

Весь код, результаты и комментарии - в ноутбуке [`notebooks/sentiment_tfidf_mlp.ipynb`](notebooks/sentiment_tfidf_mlp.ipynb)

## Результаты

Тестовая выборка - 42 085 твитов (20%).

| Модель | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| Логистическая регрессия (бейзлайн) | 0.7266 | 0.7221 | 0.7514 | 0.7365 |
| **MLP sklearn, слова (основная модель)** | **0.7268** | **0.7248** | **0.7454** | **0.7350** |
| MLP sklearn, слова + биграммы | 0.7406 | 0.7344 | 0.7671 | 0.7504 |
| MLP PyTorch, слова (CPU) | 0.7275 | 0.7248 | 0.7476 | 0.7360 |

Топ слов по весам основной модели:

- **позитив:** `хах`, `спасибо`, `приятно`, `ура`, `обожать`, `смех`, `рада`, `счастливый`;
- **негатив:** `жаль`, `обидно`, `печально`, `грустно`, `жалко`, `скучать`, `блин`, `не`.

## Ключевые наблюдения

- **Утечка метки через смайлики.** Корпус размечен автоматически по смайликам: `)` есть в 82.9% позитивных твитов
  и ни в одном негативном, `(` - в 94.7% негативных и ни в одном позитивном. Без удаления скобок модель выучила бы смайлики, а не слова.
- **MLP не лучше логистической регрессии.** На «мешке слов» скрытому слою нечего комбинировать: сеть с ~2 млн весов
  работает как один нейрон и только быстрее переобучается. Потолок задают признаки и шумная разметка.
- **Частица «не».** Модель считает `не` негативным словом само по себе: «Фильм не плохой» получается негативнее, чем «Фильм плохой»,
  а на твитах с «не» точность ниже (0.689 против 0.742). Биграммы частично исправляют это (+3.2 п.п. на таких твитах).
- **Порядок слов не виден.** «Я рад, что ты не болеешь» и «Я не рад, что ты болеешь» дают одинаковую вероятность.
- **Артефакты корпуса.** Твиты собраны с 6 декабря 2013 по 20 января 2014 года, поэтому `шерлок` (ждали новый сезон сериала)
  и `каникулы` (заканчивались) попали в негативные слова.

## Пайплайн

1. Загрузка `positive.csv` и `negative.csv` с [Kaggle](https://www.kaggle.com/datasets/maximsuvorov/rutweetcorp) (без аккаунта, по прямой ссылке).
2. Очистка регулярными выражениями: ссылки, упоминания, хештеги, всё кроме русских букв (включая смайлики), растянутые буквы, нормализация смеха.
3. Лемматизация `pymorphy3`, удаление пустых текстов, дубликатов и текстов с противоречивыми метками (226 834 → 210 421 твит).
4. Разбиение 80/20 со стратификацией.
5. TF-IDF: `min_df=5`, `max_df=0.5` (словарь 15 464 слова); параметры выбраны сравнением на валидации.
6. `MLPClassifier`: 128 нейронов ReLU, Adam, L2 `alpha=1e-2`, `learning_rate_init=3e-4`, early stopping; лучшая из трёх конфигураций.
7. Интерпретация: вклад каждого слова через оба слоя (`W1 @ W2`) и проверка на текстах из одного слова, топ-20 для каждого класса.
8. Метрики, матрица ошибок, ручные тесты, разбор слабых мест, эксперимент с биграммами.
9. Та же архитектура на PyTorch с ручным циклом обучения, Dropout и поддержкой GPU.

## Запуск

### Google Colab

Нажать кнопку **Open in Colab** выше, затем `Среда выполнения → Выполнить все`.
Полный прогон на бесплатном CPU занимает около 15–20 минут. Раздел 5 (PyTorch) быстрее на GPU:
`Среда выполнения → Сменить среду выполнения → T4 GPU`.

### Docker

```bash
git clone https://github.com/Andrey-Yurchuk/sentiment-analysis.git
cd sentiment-analysis
docker compose up -d
```

Открыть http://localhost:8888, ноутбук `notebooks/sentiment_tfidf_mlp.ipynb`, выполнить `Run → Run All Cells`.
Датасет скачивается при первом запуске в папку `data/`. Полный прогон - около 10 минут на 8 ядрах CPU.

- Jupyter доступен только с локальной машины (`127.0.0.1`) и запускается без токена.
- Контейнер работает от пользователя с UID/GID 1000. Если у вас другой UID:
  `USER_UID=$(id -u) USER_GID=$(id -g) docker compose up -d --build`.
- Остановить: `docker compose down`. Логи: `docker compose logs -f`.

### Локально без Docker

python3.12 -m venv .venv
